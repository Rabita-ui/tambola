# 🎯 Tambola House

A complete Tambola (Bingo) gaming platform built with HTML, CSS, JavaScript, and Firebase.

## 🚀 Features

- User Authentication (Login/Register)
- Wallet System with Real-time Updates
- Join Active Games
- Purchase Tickets
- View Booked Tickets
- Admin Panel for Game Management
- Real-time Database Updates

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- Firebase Authentication
- Firebase Firestore
- Firebase Realtime Database
